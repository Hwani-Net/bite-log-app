# 앱 정합성 개선 리스트 (말한 대로 작동하는 앱)

작성 2026-08-28. 전체 앱 조사(2026-08-28)와 3차 실행 중 발견을 모은 4차
작업 축. 3차(기억×예보)가 "없던 연결을 만든" 축이라면, 이번은 **앱이
사용자에게 이미 약속해 놓고 지키지 않는 것들을 지키게 만드는** 축이다.

## 결 (전략)

UI가 약속하는데 코드가 안 지키는 지점이 앱 곳곳에 있다: 알림 페이지는
공지 파서가 감시 중이라고 설명하지만 그 파서는 한 번도 실행된 적 없고,
설정의 알림 토글 3개는 아무도 읽지 않는 키에 쓰며, "조과 기록 초기화"는
로그인 사용자의 데이터를 하나도 지우지 않고, 규정 지킴이는 주꾸미를
지키지만 기록 폼에는 주꾸미가 없다. 신뢰는 차별화 축("낚시인 편")의
기반이므로, 이 거짓말들을 지우는 것이 다음 기능보다 앞선다.
