## 2. 상세 스펙

### 2.1 #10 FishDex — 방언 사전

**데이터 소스:**
- 국립수산과학원 OpenAPI (`https://www.nifs.go.kr/OpenAPI_json?id=frcenterInfo2`) — `mf_kor_dia` 필드에 방언 포함
- 지역 은어 보완: 커뮤니티 수동 입력(사용자 제안 → 관리자 승인)

**플로우:**
1. 앱 첫 설치 시 bulk API 호출 → Firestore `dialects` 컬렉션 캐싱 (1회)
2. 어종 기록·검색 시 `standardName + region` → 방언 표시
3. Gemini Vision 어종식별 결과 화면에 "이 지역에선 **뽈락**이라 부릅니다" 툴팁

**UI 위치:**
- 기록 상세 페이지 (어종명 옆 `🌐` 아이콘)
- 어종도감 전용 페이지 신설 `/fishdex`

**구현 공수:** 약 3~5일 (API bulk + JSON 스키마 + 검색 UI)

### 2.2 #9 Catch Value — 시세 대시보드

**데이터 소스:**
- 수협 위판정보 OpenAPI (data.go.kr/dataset/15012417) — 위판금액 ÷ 위판수량 = kg당 단가
- 실시간 아님(전일 위판 집계). "참고 시세" 표기 필수

**플로우:**
1. 사용자가 기록 저장 시: `species + weightKg` → 해당 어종 최근 30일 평균 위판 단가 조회
2. 기록 카드에 `💰 약 ₩12,400 (kg당 ₩15,500 × 0.8kg)` 표시
3. 통계 페이지: "이번 달 총 어획 가치 ₩X / 교통·미끼비 ₩Y / 순 가치 ₩Z"

**핵심 차별화:**
- "오늘 6시간 배에서 총 ₩82,000 어치 잡았음" — 한국인 가성비 문화 직격
- 장비 구매 결정 지원: "이 릴로 작년 +₩380,000" 자랑 스샷 SNS 공유

**PRO 기능:**
- 지역별 시세 히트맵 (어종별 가장 비싼 산지)
- 개인 ROI 분석 (낚시대 ROI, 미끼 ROI)

**구현 공수:** 약 1~2주 (API 활용신청 포함)
**블로커:** 수협 API 활용신청 승인 1~3일 대기. 대표님이 data.go.kr 신청 필요

### 2.3 #8 SafeZone — 금어기·금지구역 알림

**데이터 소스:**
- 해양수산부 금어기·금지체장 공시 문서 (mof.go.kr/doc/ko/selectDoc.do?docSeq=64389) — PDF/HWP
- 해양환경공단 해양보호구역 SHP (data.go.kr/15136101)
- 국립해양조사원 특정금지구역 SHP (data.go.kr/15116525)

**데이터 구축 방법:**
1. 에이전트가 공시 문서 PDF를 파싱 → `fishing_restrictions.json` (어종, 기간, 지역, 최소 체장)
2. SHP 파일을 GeoJSON 변환 → Firestore 저장
3. 연 1회(매년 1월 1일 법령 개정 시점) 수동 갱신 루틴 — director 스킬로 자동화

**플로우:**
1. 기록 저장 시점: GPS 좌표 + 어종 + 크기 비교
   - 금어기 어종이면 🚨 "감성돔 5/1~5/31 금어기, 방생 권장"
   - 금지 체장 미달이면 🚨 "20cm 미만은 법적 방생 의무"
   - 해양보호구역이면 🚨 "이곳은 다도해 해상 국립공원"
2. 출조 전 체크리스트 화면: "오늘 금어기 어종 3종" 표시

**핵심 차별화 + 사회적 의미:**
- 벌금 회피 가치 (500만원 이하 과태료 실제 존재)
- 해수부 협력 가능성 — 정부 PR 콘텐츠·지원금

**구현 공수:** 약 2~3주 (PDF 파싱 + GeoJSON 처리 + 지도 overlay)
**리스크:** 법령 변경 시 데이터 stale. 매년 1월 갱신 reminder 필수

### 2.4 보너스: Bite Index — 바다낚시지수

**데이터 소스:**
- data.go.kr/15142486 (해수부) — 자동승인 10,000회/일 무료

**제공 데이터:**
- 전국 주요 낚시포인트 × 어종별 낚시지수 1~5단계 (실시간)
- 수온, 파고, 물때 포함

**플로우:**
1. 서버 측 매 30분마다 포인트별 데이터 fetch → Firestore 캐싱
2. 기존 `/bite-forecast` 페이지에 오버레이 — "해수부 공식 낚시지수 오늘 4단계"
3. 사용자 GPS 반경 30km 내 최고 지수 포인트 Push 알림

**핵심 차별화:**
- 현재 BiteLog `bite-forecast`는 AI 추정 — 공식 정부 데이터 결합으로 신뢰도 폭증
- 경쟁앱 대부분 미사용 (해수부 API는 2025년 공개)

**구현 공수:** 약 3~5일 (자동승인, 기존 bite-forecast 확장)
