# 예약(booking) 개선 리스트

작성 2026-08-26. 방향(결): 예약 플랫폼은 선사 편이라 못 만드는 것 —
**낚시인 편에서 사용자의 기억·데이터·이익을 대변하는 기능** — 이 우리의
차별화 축이다. 두 기둥: ① 낚시 인텔리전스 결합(예보×예약), ② 사용자
기억 대행(이력·평가·변경 감지).

## A. 바로 가능 — 이미 파싱한 데이터로, 외부 요청 추가 없음

| # | 항목 | 내용 |
|---|------|------|
| A1 | 키워드 통합 검색 | 배 이름·항구·어종을 더피싱+낚시뚜 합쳐서 클라이언트 검색. 소스를 가로지르는 검색 자체가 개별 플랫폼에 없음 |
| A2 | 즐겨찾는 선사 | 카드에 별 버튼. **별도 기능이 아니라 "내 선사 카드"(N1)의 한 필드로 통합 설계** — 즐겨찾기·판정·이력·메모를 배(uid) 단위 저장 구조 하나로 |
| A3 | 항구(출항지) 필터 | areaPath에 항구까지 이미 있음. 권역 선택 시 하위 항구 칩 동적 생성 |
| A4 | 정원(인승) 필터 | capacity 파싱됨. 소형/중형/대형 3칩 |

## N. 사용자 기억 대행 (2026-08-26 추가 — 이번 결의 핵심 묶음)

| # | 항목 | 내용 |
|---|------|------|
| N1 | 승선 이력 + 판정 | 배 단위: 탄 날짜, 한 줄 메모, 3단계 판정(또 탄다/보통/안 탄다). 검색 카드에 배지 "⭐ 2회 승선 · 다시 타고 싶음" / "⚠️ 다시 안 탐" — 재예약 결정 순간에 과거의 내가 경고 |
| N2 | 이름·모항 변경 감지 | 더피싱 uid는 이름/항구가 바뀌어도 유지됨. 즐겨찾기·이력 저장 시점마다 이름+항구 스냅샷 → 달라지면 "이전에 '스텔라호(대천항)'였습니다" 표시. 판정·이력은 uid를 따라가므로 개명해도 배지 유지. uid가 끊기는 재등록·플랫폼 이동은 자동 매칭하지 않음(오판 위험) — "예전 그 배인가요? [같은 배로 연결]" 수동 폴백만 |
| N3 | 가격 변동 감지 | 배 상세를 볼 때마다 priceLine 스냅샷 → "지난번 조회 대비 +2만원" 표시. N2와 같은 스냅샷 패턴 |
| N4 | "다시 안 탐" de-rank | 판정 '안 탄다' 배는 검색 결과에서 흐리게 + 하단 정렬. 완전 숨김은 하지 않음(실수 방지가 목적이므로 보이되 경고) |
| N5 | 시즌 회귀 리마인더 | 승선 이력 × 시즌DB × 빈자리 알림 결합: "작년 9월 주꾸미 출조 기록 있음 → 올해 시즌 시작 + 그때 탔던 배 자리 현황" |
| N6 | 선사 소멸 감지 | 즐겨찾기·이력 있는 배가 목록에서 사라지면(uid 소멸) 알림. 조용히 깨진 즐겨찾기 방지 |
| N7 | 조과기록 배 태그 | 기록 폼에 "탄 배" 필드(이력에서 자동완성) → "이 배에서 우럭 평균 5마리" 배별 조과 통계. (기존 B-8을 이 묶음에 흡수) |
| N8 | 출항 취소 조기 경보 | 예약일 D-3~D-1에 우리 해상날씨 예보가 나쁘면 "출항 취소 가능성" 미리 알림 — 선사 통보 전에 대안 날짜 준비 가능 |

## B. 낚시 인텔리전스 결합

| # | 항목 | 내용 |
|---|------|------|
| B5 | 달력 × 입질예보 오버레이 | 배별 달력 날짜에 입질 지수/물때 점수 색 표시. "자리 있는 날 중 입질 좋은 날" 선택 — 예약 플랫폼 어디에도 없음 |
| B6 | 어종 역방향 추천 | "주꾸미 → 시즌 피크 + 향후 2주 중 예보 좋은 날 + 그날 출조하는 배" 한 번에. 검색→추천 전환 |
| B7 | 출조 전 브리핑 연동 | preTripBriefingService 재사용. 즐겨찾기/알림/이력 배의 출조일 임박 시 날씨·물때·채비 브리핑 |

## 권장 순서

1. **N1+N2+A2 묶음** — "내 선사 카드" 저장 구조 하나로 즐겨찾기·판정·이력·변경감지 동시 해결. 이번 결의 본체
2. **A1+A3+A4** — 검색·필터 보강 (N 묶음과 저장 구조 공유, 얹기 쉬움)
3. **B5** — 달력 입질예보 오버레이 ("왜 BiteLog에서 예약을 찾는가"의 답)
4. N3~N8은 1~3의 저장 구조 위에 점진 추가
