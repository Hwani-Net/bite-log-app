---
title: 항구 선택지는 캐시 적재율과 분리한다
created: 2026-09-07
type: pitfall
source: project
---

## Symptom

9월 28일 서해 실데이터 검색에서 홍원항 버튼이 없어 후속 페이지의 선박을 찾을 수 없었다.

## Cause

검색 첫 페이지와 부분 적재된 낚시뚜 디렉터리의 항구만 합쳤다. 디렉터리 캐시는 매 실행마다 177척 전체가 있다는 보장이 없었다.

## Fix

기존 `src/data/portCoords.ts`의 확인된 항구에 더피싱 권역 코드를 붙여, 지역·검색어가 맞는 알려진 항구와 실제 응답의 항구를 합친다. 알려진 항구 목록은 전체 항구나 특정 날짜의 출항·잔여석을 보장하지 않는다.

## Prevention

`e2e/booking-recovery.spec.ts`의 디렉터리 0건 → 홍원항 선택 → 첫 페이지 0건 → 다음 페이지 선박 표시 케이스를 유지한다. 지역 변경 중 이전 지역 항구가 남지 않는 테스트도 함께 실행한다. 실데이터 확인: 2026-09-07, `e2e/booking-full-journey-live.spec.ts`, 조회일 2026-09-28.
