# Play Store 등록 정보

## 앱 이름
BITE Log — 바이트로그

## 간단한 설명 (80자)
AI 입질예보 + 조과기록 + 선단레이더. 낚시의 시작과 끝을 한 앱에서.

## 자세한 설명
🎣 BITE Log — 당신의 스마트 낚시 파트너

출조 전 날씨와 입질 확률 확인부터, 현장에서 조과 기록, 귀가 후 분석까지.
낚시에 필요한 모든 것을 AI가 도와주는 올인원 낚시 앱입니다.

■ AI 입질 예보
수온·물때·바람·기압·시간대·월상 7가지 요소를 실시간 분석.
오늘 몇 시에 어떤 어종이 잘 잡히는지 한눈에 확인하세요.

■ 스마트 조과 기록
사진 찍으면 AI가 어종을 자동 식별!
날씨·위치·물때가 자동으로 기록되어, 3탭이면 조과 기록 완료.

■ Fleet Radar (선단 레이더)
AIS 기반 실시간 선박 위치 추적.
주변 대형 선박 접근 알림으로 안전한 낚시를 즐기세요.

■ AI 컨시어지
"오늘 제주에서 뭐가 잘 잡혀요?" — AI에게 물어보세요.
장비·채비·포인트까지 맞춤 추천.

■ 시즌 예측
치어 방류 데이터 기반 어종별 시즌 분석.
금어기·체장 규정도 한눈에.

■ 통계 & 랭킹
내 낚시 패턴을 데이터로 분석.
전국 낚시인 랭킹에서 나의 순위를 확인하세요.

■ 커뮤니티 피드
다른 낚시인의 조과를 실시간으로 구경.
좋아요·댓글로 소통하세요.

[주요 특징]
✅ 7가지 요소 AI 입질 예보
✅ 사진 기반 AI 어종 식별
✅ AIS 선단 레이더 (안전)
✅ AI 낚시 컨시어지
✅ 시즌 예측 + 금어기 가이드
✅ 조과 통계 + 랭킹
✅ 오프라인 기록 지원
✅ 다크 모드
